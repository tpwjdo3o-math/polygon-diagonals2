👉 기준 꼭짓점 A에서 다른 점들을 직접 눌러 연결해보세요!

이웃한 점이나 자기 자신을 누르면 무슨 일이 일어날까요?

알림
현재 연결한 대각선: 0 / 2개
꼭짓점별 발사 현황: 0 / 5개 점 완료
중복선(양방향 2가닥) 처리:
상태: 두 번씩 센 상태 (2배)
대각선 공식 유도 현황 오각형 (n=5)
1 한 꼭짓점에서 그을 수 있는 대각선 n - 3
5 - 3 = 2개

자기 자신(1개)과 바로 옆 양쪽 이웃(2개) = 3개 제외!

2 모든 꼭짓점에서 단순 계산 시 n × (n - 3)
5 × 2 = 10개 (중복 포함)

꼭짓점 5개마다 각각 2개씩 쏘았으므로 곱함!

3 실제 대각선의 총 개수 n(n - 3) / 2
10 ÷ 2 = 5개

대각선 1개는 양쪽 끝 점(A→C, C→A)에서 2번씩 겹쳐 셌으므로 2로 나눔!
